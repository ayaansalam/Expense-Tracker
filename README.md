# expense tracker

Small web app to track spending, made with Flask and SQLite. Expenses get saved in SQLite and you can see a bar chart of spending by category.

Features:
- Add, view and delete expenses
- Group by categories and sort by amount
- Total spending across each category
- Search by category

To run:
```
pip install flask
python expense-tracker.py
```

Then open http://127.0.0.1:5000
